## ✨ المميزات

### 📊 إدارة التقارير

- **التقارير اليومية**: إنشاء وتحويل التقارير اليومية إلى PDF
- **التقارير الشهرية**: تجميع البيانات الشهرية وإنشاء التقارير
- **تقارير الجودة**: مراقبة وتحليل جودة المياه والعمليات
- **تقارير الحمأة الجافة**: إدارة اختبارات الحمأة والتحاليل

### 🧪 الوحدات التحليلية

- **تحليل المواد الكيميائية**: حساب تركيز المركبات والأوزان
- **اختبارات اليود**: إعداد وتحليل عينات اليود
- **اختبارات الصوديوم**: تحليل محتوى الصوديوم
- **عامل TDS**: حساب عامل الجفاف الكلي للمياه
- **نطاق COD**: تحليل الطلب الكيميائي للأكسجين

### 🎨 واجهة المستخدم

- واجهة رسومية سهلة الاستخدام بـ tkinter
- دعم كامل للغة العربية والإنجليزية
- تقويم تفاعلي لاختيار التواريخ
- تصميم احترافي ومرن

### 📁 إدارة الملفات

- دعم ملفات Excel (.xlsx) للبيانات والقوالب
- تحويل تلقائي إلى PDF
- نظام نسخ احتياطي تلقائي
- تنظيم الملفات حسب التاريخ والنوع

## 🔧 المتطلبات

### المتطلبات الأساسية

- **Python 3.8 أو أحدث**
- **Windows 10/11** (أو Linux/Mac مع تعديلات)

### المكتبات المطلوبة

```
tkinter          # واجهة المستخدم (مدمج مع Python)
openpyxl         # معالجة ملفات Excel
tkcalendar       # تقويم تفاعلي
pandas           # معالجة البيانات
reportlab        # إنشاء ملفات PDF
Pillow           # معالجة الصور
```

### المتطلبات الاختيارية

- **PyInstaller** لإنشاء ملفات تنفيذية
- **Inno Setup** لإنشاء مثبت Windows

## 🚀 التثبيت

### 1. تثبيت Python

```bash
# تحميل Python من الموقع الرسمي
https://www.python.org/downloads/
```

### 2. تثبيت المكتبات المطلوبة

```bash
pip install openpyxl tkcalendar pandas reportlab Pillow
```

### 3. تحميل المشروع

```bash
git clone https://github.com/krugerlab/Kruger-Lab-System.git
cd Kruger-Lab-System
```

### 4. تشغيل البرنامج

```bash
python app.py
```

## 📖 الاستخدام

### بدء التشغيل

1. قم بتشغيل `app.py`
2. ستظهر لك القائمة الرئيسية
3. اختر النوع المطلوب من التقارير

### إنشاء تقرير يومي

1. اختر "التقرير اليومي" من القائمة
2. حدد التاريخ باستخدام التقويم
3. اختر الملف المصدر
4. اضغط "إنشاء التقرير"

### إعدادات البرنامج

- يمكن تخصيص المسارات والإعدادات من خلال `settings_module.py`
- ملفات الإعدادات موجودة في مجلد `Setting/`

### هيكل المجلدات

```
D:\Plant Reports\
├── Daily Reports\        # التقارير اليومية
│   ├── Daily Sheets\    # ملفات Excel الأصلية
│   └── Daily PDFs\      # ملفات PDF المحولة
├── Quality\             # تقارير الجودة
├── Dry Sludge\         # تقارير الحمأة
├── External Plants\    # تقارير المحطات الخارجية
├── Monthly Report\     # التقارير الشهرية
├── Setting\            # ملفات الإعدادات والقوالب
├── Backup\             # النسخ الاحتياطية
├── Temp\               # الملفات المؤقتة
└── Logs\               # ملفات السجل
```

## 🏗️ البناء والتوزيع

### إنشاء ملف تنفيذي (EXE)

```bash
# استخدام PyInstaller
pyinstaller Kruger_Lab_System.spec

# أو استخدام السكريبت الجاهز
python build_v2.0.bat
```

### إنشاء مثبت Windows

```bash
# استخدام Inno Setup
# افتح KrugerSetupScript.iss بـ Inno Setup Compiler
# اضغط Build -> Compile
```

### ملفات البناء

- `Kruger_Lab_System.spec` - إعدادات PyInstaller
- `KrugerSetupScript.iss` - سكريبت التثبيت
- `build_v2.0.bat` - سكريبت البناء التلقائي
